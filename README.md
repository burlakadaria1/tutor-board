# Моя доска

Первая версия онлайн-доски для репетитора.

## Запуск локально

1. Установите Node.js LTS.
2. В терминале в папке проекта выполните `npm install`.
3. Выполните `npm run dev` и откройте адрес из терминала.

## Публикация на Vercel

1. Загрузите файлы проекта в новый репозиторий GitHub.
2. В Vercel выберите Add New → Project и импортируйте репозиторий.
3. Framework Preset: Vite; Build Command: `npm run build`; Output Directory: `dist`.
4. Нажмите Deploy. Ссылка будет доступна после завершения сборки.

Содержимое хранится в localStorage устройства, а не на сервере. Для iPad и компьютера это разные данные. Не храните персональные данные учеников на публичной доске.
